# Shirudo: Tate's notes

> **Original project: [github.com/shirudo-dev/shirudo](https://github.com/shirudo-dev/shirudo)**

> **Original project**: https://github.com/shirudo-dev/shirudo

This folder contains notes, drafts, code, and fixes related to the Shirudo project, a Linux runtime security platform that uses eBPF-based "shields" to temporarily block exploit behaviors while patches are tested and deployed.

The project is developed by OpenAI and Cisco, with a BSD-2-Clause license. It includes components like signed shields (backed by TPM), a guardian agent, and agent-written shields approved by security teams.

Files in this folder:
- `NOTES.md`: A dated log of what was learned or changed.
- `IDEAS.md`: Ideas for contributions with their status.
- `drafts/`: Draft documents, fixes, and proposals.
- `code/`: Test code or example scripts created during analysis.
- `fixes/`: Patches to the project that could be contributed back.
