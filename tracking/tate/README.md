# Shirudo: Tate's notes

> **Original project: https://github.com/shirudo-dev/shirudo**

This folder contains my notes, drafts, and findings while tracking the Shirudo project. Shirudo is an eBPF-based Linux runtime security platform that applies temporary "shields" to block exploit behaviors while patches are tested and rolled out.

## Contents

- `NOTES.md`: A dated running log of what I learned and what changed.
- `IDEAS.md`: Contribution ideas with their status.
- `drafts/`: Write-ups, docs fixes, design notes.
- `code/`: My own code or experiments.
- `fixes/`: Patches for the project.
