# Shirudo Contribution Ideas

This file tracks potential contribution ideas for the Shirudo project, with their status.

## Ideas

1. **Improve Quick Start Guide**
   - Status: Not started
   - Difficulty: Low
   - Description: The quickstart guide is missing information about the checkout directory on the target system. This would help users follow the guide more easily.
   - First step: Review the current quickstart guide and propose changes to include the checkout directory.

2. **Write unit tests for `upatch_table.c`**
   - Status: Not started
   - Difficulty: Medium
   - Description: There is an open issue (#255) requesting unit tests for `upatch_table.c`. This would improve code quality and test coverage.
   - First step: Create a test file that covers the functions in `upatch_table.c`.

3. **Create example shield implementations**
   - Status: Not started
   - Difficulty: Medium
   - Description: The documentation lacks example shield implementations. Creating these would help users understand how to write shields.
   - First step: Write a simple shield implementation and document it.

4. **Enhance documentation around TPM integration and VM testing**
   - Status: Not started
   - Difficulty: High
   - Description: Documentation on TPM integration and VM testing is sparse or incomplete. Expanding these sections would help users set up and use these features.
   - First step: Review the current documentation and identify gaps.
